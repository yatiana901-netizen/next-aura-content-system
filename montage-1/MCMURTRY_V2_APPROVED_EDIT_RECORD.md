### Motion implementation

- Crop position interpolates with cosine easing: `e(t) = (1 - cos(pi * min(t/duration, 1))) / 2`; position = start + delta × e(t).
- Zoom uses the same eased shape across output frames: `z(n) = z0 + (z1-z0) * (1-cos(pi*n/(frames-1)))/2`.
- Zoom is centered within the moving crop. Directional pan carries the attention target; zoom controls its emphasis.
- The largest animated enlargement is 1.00 → 1.16. Some shots pull out; the payoff uses 1.02 → 1.09. These are episode settings, not mandatory presets for every source.
- Foreground is scaled to 2160 pixels wide before zoompan and returned to 1080 pixels wide, preserving the crop aspect ratio and centering vertically. Upscaling cannot restore detail missing in the original.
- Background uses a separate copy: scale/crop to 216 × 384, Gaussian blur sigma 13, darken by 0.13 and reduce saturation to 0.72, then scale to 1080 × 1920.
- Mild shared correction before splitting: brightness +0.02, contrast 1.035, gamma 1.025, saturation 1.04. Adapt these to future footage, not blindly to every video.
- The alternate proof view selects the relevant panel from multi-camera footage. Track crops remove source letterboxing.
- No blanket transition plugin was added. Clean cuts, shot direction, changing scale and synchronized SFX carry the transitions.

Processing: decode mono 48 kHz float; second-order high-pass at 100 Hz; locate strongest energy peak using a 480-sample energy window; take a short slice starting up to 0.12 seconds before that peak, up to 0.36 seconds long. Normalize to the cue level; apply short entry/exit fades; place the peak on the listed beat. At the very start, negative lead-in samples are trimmed. The cue table lists peak/beat targets, not file start times.

A 960-sample VO RMS envelope reduces the SFX stem by up to 35% during stronger speech. Mix with VO; limit to 0.89 amplitude without automatic gain, then loudness-normalize output to -16 LUFS, -1.5 dBTP, LRA target 7. Actual measured LRA is 1.7 LU, not 7 LU. Levels in the table are pre-ducking and pre-final-normalization, not promised final cue loudness.

Do not replace this with one sound mechanically repeated on every cut. Match the energy and meaning, keep speech clear, and listen to the export when playback is available. No music or musical stingers.

## 9. Rebuild and version control

Download the recipe ZIP linked above. Install Python 3, numpy, scipy, FFmpeg/ffprobe. Download the six linked media files into `sources/` beside `build_v2.py`, keeping the exact source-map filenames. Run `python3 build_v2.py`; output goes to `v2/NEXT_AURA_MCMURTRY_V2.mp4`.

The script writes edit_plan_v2.json, sfx_cues_v2.json, mix_v2.wav and per-shot segments. Generated segment files are cached: after changing a shot, remove only its `v2/segments/NN.mp4` (zero-based index) before rerunning, otherwise the old shot is reused. Any VO/timing change requires a full affected-shot/audio timing review. Preserve previous versions; never silently pair new text with an old take.

The ZIP includes original and clean voice audio, the pressure overlay and SFX. GitHub stores this record and the text build script; the large source videos remain linked. This recipe is reproducible provided the linked source files remain accessible.
