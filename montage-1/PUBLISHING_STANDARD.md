# Publishing & Growth Standard — Required for EVERY NEXT AURA Video
**Status:** Permanent Montage 1 workflow requirement · added 2026-11-03

All finished videos must be accompanied by a **four-part Publishing Pack** (the user explicitly requires this every time):
1. **TikTok thumbnail / Miniature:** deliver a purpose-built vertical 9:16 JPG/PNG file.
2. **One strongest German SEO title/caption:** copy-ready; exact topic/product name + most searched factual keyword(s) + truthful tension/curiosity, no clickbait.
3. **EXACTLY FIVE German-market relevant hashtags:** one/two exact model/brand hashtags plus niche and topical discovery tags; avoid generic #fyp/#viral padding.
4. **Recommended publish day/time:** give **exact calendar date**, **Morocco local hour**, **Germany local hour**, timezone labels and rationale with recent evidence/analytics. No fixed universal posting hour; retune for each upload.

### Thumbnail standard (mandatory)
- Produce a fresh attractive **9:16** (recommended 1080×1920) cover from verified topic footage where possible; do not use AI images claiming to be official photographs.
- Strong one-subject composition, true-to-model car or engineering hardware, realistic cinematic lighting, premium contrast and sharpness.
- Very short German headline (ideally 2–5 words or a striking verified figure), big enough to be readable in the TikTok profile grid.
- Keep all essential text/subject in center safe region (avoid TikTok overlays and clipping in square-ish grid thumbnail); check on small phone size.
- Do **not** overload specs, giant stickers, logos or misleading future claims. Verify car/body shape and factual details before finalizing.
- Generate 1 best candidate, critique objectively, revise or replace poor work, and deliver PNG/JPG; save alongside the final MP4.

### German search/SEO workflow (mandatory)
- Identify actual search intent and exact product/entity spelling, e.g., `ABT RS5-R`, `Audi RS5`, `ABT Sportsline`, `720 PS`, `62000 Euro`.
- When possible use TikTok's current search suggestions/Creator Search Insights or equivalent real search checks; **do not pretend to have checked search volumes** if unavailable.
- Title should be naturally written in German, include 1–3 key terms and a hook. Do not keyword-stuff or make promises not supported by official facts.
- Five hashtags must be **unique, relevant, and case-preserving as useful**; prioritize exact topic over broad #fyp tags.
- Provide everything in one copy-ready post caption; keep the 5 hashtags immediately beneath.

### Publish-time workflow (mandatory)
- Determine requested date **relative to the user's timezone**, today/tomorrow, via a current local clock when available.
- Verify latest Moroccan timezone rules explicitly; **from 2026-09-20 Morocco uses GMT/UTC+0**, while Berlin is CET (UTC+1) in November 2026. Old OS tzdb versions may show an outdated Moroccan offset; confirm with fresh authoritative web sources.
- Check latest reliable posting studies *and* user account's TikTok audience analytics when accessible. Generic averages are a **starting experiment**, not a guaranteed best time.
- Give one primary recommended posting hour with both timezones and optional alternate if materially useful. Explain how to compare results for next posts.

### Required final delivery for every video
- Verified MP4.
- Downloadable TikTok cover (9:16) including source/rights note.
- Copy-ready German Title + **5 hashtags**.
- Exact date and Morocco/Germany posting times.
- Optional pinned engagement comment if it fits the topic.
- Short factual QA note: factual claims, framing/sync and asset license status.
- Store a dated `PUBLISHING_PLAN.md` and thumbnail file inside each local project ZIP, plus link/repository doc in GitHub.

**Do not silently omit any of the four deliverables.** If lack of tooling prevents a file upload or current keyword inspection, say what is missing and supply the strongest supported partial result.
