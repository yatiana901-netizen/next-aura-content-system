# TikTok Search Strategy — Canonical

## Creator Search Insights
When available on the account, use **Creator Search Insights** before choosing topics.

Prioritize:
- high-interest search topics
- "content gap" topics
- niche-relevant German search demand

TikTok states that search value can contribute to Creator Rewards value.

## Search-first topic test
For each candidate topic, identify one main German search intent, for example:
- BMW iX5 460 kW
- 800 Volt Elektroauto
- F1 Bremse erklärt
- Megayacht Stabilisator

## Natural keyword placement
Use the core concept naturally in:
- spoken hook or early VO when appropriate
- caption
- limited on-screen text
- relevant hashtags

Do not keyword-stuff.

## Research vs trend-chasing
Search demand is a filter, not the entire strategy.
A strong Next Aura topic still needs:
- hidden technical angle
- real visual story
- accurate explanation
