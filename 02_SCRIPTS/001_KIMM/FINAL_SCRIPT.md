# 001 — KIMM Sound-Emitting Display

## Final angle
A display where the sound can originate from the same on-screen location as the visible source.

## Core facts used
- display surface generates sound through controlled vibration
- prototype uses 80 voice-coil actuators
- software calculates which actuators should operate
- AI can localize/separate sound sources
- reported target-zone selection accuracy: 99.9%

## Final concise VO
Bewegt sich dieser Mann nach rechts, wandert seine Stimme einfach mit. Und nein: Hinter dem Bildschirm fährt kein Lautsprecher herum. Der Bildschirm selbst erzeugt den Ton. Dafür sitzen auf seiner Rückseite 80 kleine Voice-Coil-Aktuatoren, die ausgewählte Bereiche des Panels in winzige Schwingungen versetzen. Das Problem: Der Bildschirm ist eine zusammenhängende Fläche. Bewegst du eine Stelle, breitet sich die Vibration normalerweise weiter aus. Das System misst zuerst, wie jeder Aktuator die gesamte Fläche beeinflusst, und berechnet dann, welche Motoren wie stark arbeiten müssen, damit nur die gewünschte Zone deutlich schwingt. Zusätzlich erkennt eine KI, wo sich die Schallquelle im Video befindet – und kann einzelne Geräusche voneinander trennen. In Tests traf das System die gewünschte Zielzone mit 99,9 Prozent Auswahlgenauigkeit. Der Trick ist, Bildposition, Software und Vibration so präzise zu verbinden, dass der Ton genau dort entsteht, wo du ihn siehst.
