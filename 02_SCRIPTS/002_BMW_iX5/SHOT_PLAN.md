# 002 BMW iX5 — Approved Shot Logic

## Target
~60–65 seconds.

## Structure
1. Hook: charging / hero footage
2. Short presenter reveal: 800V is the more interesting number
3. Gen6 / battery / 800V technical visual
4. High-voltage / cable / power-electronics explanation
5. Battery / cylindrical-cell system mention
6. Real charging footage: 10–80% in 22 min
7. Reality check: 460 kW = peak
8. Short presenter pattern reset
9. Final hero / charging payoff

## Visual-writing lesson
Do not force:
- 400V vs 800V bespoke animation
- microscopic cylindrical-cell footage
- exact current calculations
unless the footage already exists.

Rewrite the VO so available visuals can carry it accurately.

## Presenter
Keep appearances short.
Do not end on a long talking-head shot; return to a strong BMW / charging visual for the final payoff.
