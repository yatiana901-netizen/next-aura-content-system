# Analytics Scorecard — Canonical

## Why
Do not judge videos by views alone.
Use analytics to identify which **topic + hook + visual pattern** actually works.

## Record for every published video
### Identity
- Video ID
- Topic pillar
- Brand / subject
- Hook type
- Duration
- Presenter appearances
- Main visual type
- Publish date / time

### Performance checkpoints
Record at:
- 1 hour
- 24 hours
- 72 hours
- 7 days

### Metrics
When available:
- views
- average watch time
- average % watched
- full-watch / completion rate
- 2s / 3s / 5s retention or closest available retention data
- likes
- comments
- shares
- saves
- profile visits
- follows attributed to video
- search traffic
- top search queries
- Germany audience %
- For You traffic %
- Creator Rewards qualified views
- RPM / rewards once eligible

## Normalize engagement
Also calculate per 1,000 views:
- shares / 1k
- saves / 1k
- follows / 1k
- comments / 1k

## Benchmark rule
Do not use random internet thresholds as truth.
Compare each video against:
- median of the previous 10 comparable videos
- median of the same content pillar
- account trend over time

## Promote lessons
A lesson enters MASTER rules only after repeated evidence across multiple videos, not because one video went viral.
