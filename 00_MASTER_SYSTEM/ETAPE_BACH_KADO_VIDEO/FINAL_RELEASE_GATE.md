# Final Release Gate — mandatory approval checklist

## Editorial / accuracy
- [ ] Source dates and all specs independently verified and correctly described
- [ ] Model/prototype/concept labels correct, shots actually show the subject
- [ ] Claims in captions/thumbnail backed by evidence

## Footage / legal
- [ ] All real clips, creator footage, VO and SFX have documented rights/permissions
- [ ] AI visuals/representations correctly disclosed where required
- [ ] No copied platform watermarks or misleading reversed badges

## Video and sound QA
- [ ] Export watched in full and important cuts checked frame-by-frame
- [ ] German VO listened for actual pronunciation and pacing
- [ ] Real word onset aligned with text/card appearance and SFX transient
- [ ] No music in ANY layer including background footage, effects or transitions
- [ ] Voice never masked; verified source sounds only; fades and sound provenance logged
- [ ] 9:16 tracking does not lose the subject, no black frames/frozen cuts
- [ ] FFprobe full decode, duration, fps, codecs, dimensions verified (where available)
- [ ] LUFS / true peak measured if available, or clearly NOT MEASURED
- [ ] Reviewer independent of editor when possible; limitations disclosed

## Packaging and release
- [ ] MP4 actually exists and was verified, never a guessed sandbox link
- [ ] Instagram/TikTok/YouTube cover crops safe and legible
- [ ] TikTok has exactly 5 relevant hashtags
- [ ] YouTube Title, Description and SEO Tags checked, no spam
- [ ] No near-identical upload duplication without separate story value
- [ ] Publish ONLY after explicit user approval

**Signoff:** reviewer ___ | date ___ | status PASS / PENDING / BLOCKED | critical issues ___
