# 08 — Animations, Non-Musical SFX & Transitions

**User command:** `8` • **Legacy SOP map:** Stages 6 + 7

## الهدف
مونتاج Premium مؤثر، بأصوات غير موسيقية ومتزامنة مع الكلمات.

## Inputs / شنو خاصنا
- First Cut + VO_CUES + SFX library

## Execution / شنو غادي نخدمو
1. Info Cards مهمة فقط 2–5 كلمات، فوق الـsubject أو safe area، بلا subtitles مستمرة افتراضياً
2. حركات Clean: pop/slide/ease على الكلمات والأرقام فقط، خرج النص قبل Cut
3. SFX whoosh/impact/click فقط إذا يدعم حركة أو كشف معلومات
4. ممنوع الموسيقى كلياً، وحتى الرّايزر النغمي أو melodical SFX ممنوع
5. افحص الأصوات سماعياً؛ لا تعتمد على اسم الملف؛ إذا شكّ فموسيقى استبعده
6. احتفظ بالصوت الطبيعي للمحرك فقط إذا حقيقي ومرخص وخالٍ من music؛ وإلا mute
7. اعمل voice-priority ducking وfades وتجنب masking وSFX الضعيف

## Mandatory pre-delivery review
- [ ] كل transient SFX موافق للـVO والكادر
- [ ] الـVO واضح في كل كلمة ولا Clipping
- [ ] no music، لا علامات أو نصوص كبيرة على الشاشة
- [ ] راجع اللغة، دقة الأرقام، تسميات الملفات، التوافق مع المراحل السابقة وأي نقص.
- [ ] سجل الأدوات والمراجعات التي تمت فعلاً؛ إذا ما تمش السماع أو مشاهدة الفيديو فصرّح بذلك.

## Outputs / شنو غادي نسلم
- MIXED_REVISION.mp4 إذا أمكن فعلياً
- SFX_AND_CARD_CUES.csv
- AUDIO_PROVENANCE.md
