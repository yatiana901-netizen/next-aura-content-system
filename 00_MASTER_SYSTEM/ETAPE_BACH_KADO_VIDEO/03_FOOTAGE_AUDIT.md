# 03 — Footage Research & Audit

**User command:** `3` • **Legacy SOP map:** Stage 0 + Stage 3

## الهدف
نأكدو أن عندنا فيديوهات أصلية كافية كتشرح كل فكرة.

## Inputs / شنو خاصنا
- الـFacts ومكتبة الفيديو الخاصة وروابط المصادر

## Execution / شنو غادي نخدمو
1. ابحث عن لقطات حقيقية OEM / demonstrations / creators مع سجل استعمالها
2. افتح الفيديوهات ودوّن دقة الصورة وFPS والمدة والحركة ومصدر الصوت
3. حدد المقاطع المفيدة ودقائق Source IN/OUT الأولية؛ تمييز اللقطات المكررة
4. استبعد blur، كادرات السيارات الغلط، clips ضعيفة أو AI-fake hardware
5. دوّن لكل لقطة الحقوق، الظهور الحقيقي، وما إذا فيها صوت موسيقي مدمج
6. لو فيديوهان من نفس الموضوع: زاويتان وshot pools مختلفان قدر الإمكان

## Mandatory pre-delivery review
- [ ] كل لقطة مطابقة للموديل أو التكنولوچيا
- [ ] الحقوق غير مفترضة لمجرد أن الفيديو على YouTube
- [ ] الـFootage الأصلية متنوعة وكافية من غير حشو
- [ ] راجع اللغة، دقة الأرقام، تسميات الملفات، التوافق مع المراحل السابقة وأي نقص.
- [ ] سجل الأدوات والمراجعات التي تمت فعلاً؛ إذا ما تمش السماع أو مشاهدة الفيديو فصرّح بذلك.

## Outputs / شنو غادي نسلم
- FOOTAGE_INVENTORY.csv
- RIGHTS_LEDGER.md
- MISSING_SHOTS_AND_KEYWORDS.md

## Completion gate
لا تتعهد بإنتاج بصري مطابق إذا اللقطات أو الحقوق غير متوفرة.
