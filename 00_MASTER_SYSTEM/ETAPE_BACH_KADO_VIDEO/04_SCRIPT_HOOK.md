# 04 — German Script & Hook

**User command:** `4` • **Legacy SOP map:** Stage 1

## الهدف
نص ألماني طبيعي وقوي من أول ثانية مع معلومة تقنية حقيقية.

## Inputs / شنو خاصنا
- FACT_LEDGER + موجودات footage

## Execution / شنو غادي نخدمو
1. صغ 2–3 Hooks مختلفة وقارن علاش كل واحدة كتشّد
2. أول 2–3 ثواني سؤال أو لقطة قوية؛ أول 8–9 ثواني خاصها تبني الفضول
3. قدّم أول مكافأة معلوماتية مبكراً ثم سبب جديد للمواصلة
4. اربط كل جملة بلقطة قابلة للاستعمال، وتفادى claims غير مثبتة
5. لا تفرض مدة 60 ثانية، ولا تكرر كلمة أو فكرة، ولا تجعل CTA مصطنعة
6. ألمانية بسيطة وسليمة مناسبة لمستمعي ألمانيا، بلا تضليل أو خلط تقني

## Mandatory pre-delivery review
- [ ] كل جملة مدعمة بالـFact Ledger
- [ ] الـHook له دليل بصري
- [ ] لا انقطاع مفاجئ ولا filler واللغة طبيعية
- [ ] راجع اللغة، دقة الأرقام، تسميات الملفات، التوافق مع المراحل السابقة وأي نقص.
- [ ] سجل الأدوات والمراجعات التي تمت فعلاً؛ إذا ما تمش السماع أو مشاهدة الفيديو فصرّح بذلك.
