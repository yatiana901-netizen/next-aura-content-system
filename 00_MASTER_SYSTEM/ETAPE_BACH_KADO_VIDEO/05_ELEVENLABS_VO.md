# 05 — ElevenLabs VO Selection

**User command:** `5` • **Legacy SOP map:** Stage 2

## الهدف
نختار أحسن أداء حقيقي ديال Jan v4 بلا تخريب صوت أو نطق.

## Inputs / شنو خاصنا
- السكريبت النهائي، تسجيلات الـTakes إن توفرت

## Execution / شنو غادي نخدمو
1. قارن 2–4 Takes بالنطق الألماني والوقفات والإيقاع والطاقة عند توفرها
2. استمع فعلاً لأهم 3 ثواني ثم التسجيل كاملاً؛ لا تعتمد على المدة فقط
3. وثّق مشاكل النطق والأرقام والتقطيع والتشويه والـclipping
4. اختار Take واحد أو طلب إعادة سطر محدد إذا لزم، مع أقل تعديل ممكن
5. سجل المدة الأصلية وملف VO المختار وبدايات الكلمات المهمة من الموجة والسماع

## Mandatory pre-delivery review
- [ ] الـTake النهائي مسموع ومفحوص فعلاً أو صرّح بعدم إمكان فحصه
- [ ] لا speed-up يفسد Jan
- [ ] قيمة كل كلمة تقنية والنطق مفهومة
- [ ] راجع اللغة، دقة الأرقام، تسميات الملفات، التوافق مع المراحل السابقة وأي نقص.
- [ ] سجل الأدوات والمراجعات التي تمت فعلاً؛ إذا ما تمش السماع أو مشاهدة الفيديو فصرّح بذلك.
