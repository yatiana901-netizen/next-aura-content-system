# Visual Rules

## Priority
1. Official / original footage of the exact project
2. Licensed or legitimate supporting footage
3. Technical graphics
4. AI illustration only when real footage cannot show the mechanism

## Shot matching
Every important sentence needs a specific visual.
Do not use random B-roll simply to fill time.

## Search
Use exact project names, company names, technical feature names and official titles before generic keywords.

## TikTok framing
- 9:16
- Keep the important object inside safe areas
- For horizontal footage, crop intelligently when possible
- If cropping destroys the technical information, use a restrained background treatment in CapCut
- Avoid heavy baked-in tracking/blur renders that degrade quality

## Presenter
Do not use on a fixed schedule.
Use only as:
- hook
- pattern interrupt
- clarification
- reveal
- payoff

Avoid repeating the same gestures and timings across videos.
