# NEXT AURA — PHOTO NEWS CAROUSEL STANDARD (Pilot v0.1)
**Date:** 2026-11-06 | **Status:** USER-REQUESTED NEW FORMAT, UNTESTED PERFORMANCE
**Purpose:** An additional photo-only editorial news format for Next Aura Germany; **does not remove or replace** the 12-stage video workflow. No automatic claim that carousels outperform videos.

## User's creative direction
Create compelling swipeable **TikTok Photo Mode** posts about brand-new underreported AutoTech/mobility engineering news. Strong meaningful photography, succinct German on-image headlines and factual payoffs. Each image must look professionally art-directed, not obviously AI-generated or like generic templates. Every swipe gets a new fact and a genuine reason to proceed to the next.

## Editorial rules
1. Topic research: prefer news from the last 24–72 hours, widen to a week only when relevant; date check official press release and reprints. Avoid old material framed as breaking.
2. Fact lock first: manufacturer source and independent cross-check as needed; distinguish prototype/concept/production and planned capabilities. No exaggerated 'world first', launch dates, exact specifications, or fake engineering imagery.
3. Visual proof: 1–2 credible anchor photos/stills of the actual technology with confirmed use rights, plus genuinely original labeled diagrams where needed. Merely seeing a photo publicly does not grant redistribution rights. A manufacturer press kit can have strict editorial-use limitations.
4. Photo Mode = **manually swipeable photos**, not rendered autoplay slideshow/video. Target 1080x1920 (9:16) or quality appropriate for platform; keep safe text area away from right-side UI and caption/buttons.
5. **Pilot ~7 slides**, generally 5–8 depending on real story. Number is an experiment, not a TikTok algorithm guarantee or compulsory minimum; if content only supports 4 strong slides, publish 4 and remove padding.
6. Slide 1 = compelling REAL subject plus short true headline and curiosity gap. Strong first-frame visual; no dishonest reveal.
7. Each following slide = exactly one genuinely new idea, ideally <= 12–18 German words in visible large typography; text length is art-direction default, adjust for accuracy. One impactful hierarchy per slide: headline, occasional tiny qualifier/date/source, high visual quality. No long paragraphs.
8. Slide progression default: 01 STOP-SCROLL → 02 SURPRISE → 03 HOW IT WORKS → 04 ENGINEERING PAYOFF → 05 WHY IT MATTERS → 06 LIMITATION / PROTOTYPE STATUS → 07 DEBATE / USEFUL TAKEAWAY. Reorder for the story; never conceal a safety-critical caveat to manipulate curiosity.
9. Maintain an editorial premium design system: authentic high-resolution images, cinematic but realistic color, clean 1–2 font families, white/charcoal typography and restrained Next Aura brand accent. No generic AI-looking gadgets, heavy neon, noisy stickers, impossible reflections, misleading HUD mockups or falsely labeled prototype screenshots. Images may be AI-assisted only when intentionally illustrative and clearly identified, where appropriate.
10. Consistency: recurring slide index `01/07`, subtle Next Aura signature, consistent margins/contrast, but change photography and composition for each slide. Do not recycle identical image with a different caption as multiple slides.
11. No music, including audio added when publishing. No need for VO/SFX or video transitions in photo-only format. User's global no-music rule remains.
12. Don't promise virality. After publishing, measure reach, saves, shares, comments and completed swipes **only where platform analytics exposes those data**. Compare with other Next Aura videos with transparent limits.

## Slide by slide approval process — REQUIRED
- First draft: supply just story arc + German copy for all proposed slides, with exact factual citations and candidate photo origin for each.
- Then produce **Slide 01 only** when the user requests making the image. Show the result and perform detailed QA: legibility at phone size, correct subject/photo identity, actual sourced claim, visual impact, copyright rights, safe zones, text spelling, brand style.
- If user rejects the image, revise **that slide**. If user wants prompt modifications or better real photo, report and fix, not defend weak visuals.
- Only after user is happy with Slide 01 move to Slide 02, etc.; don't generate seven low-quality images at once by default.
- Stage 03 media rights gate still applies even though it is a photo post. All factual image reuse requires lawful rights or original created design.
- Final package: numbered `slide_01.png` through `slide_NN.png`, Photo Mode posting order, German description, **exactly 5 relevant German-targeted hashtags**, source/rights references, and pre-publish visual QA. Save file assets in private Google Drive `05_BRAND_AND_COVERS` or a purpose-built Photo News folder, not in GitHub.

## QA to run before delivering EACH slide
- [ ] Visual clearly depicts exact model/technology, or is visibly labeled original schematic
- [ ] Source/credit/permission logged; not a copied Instagram/TikTok screenshot or unlicensed photo
- [ ] Hook and numbers have authoritative evidence; no conflation of technologies
- [ ] German orthography and factual qualifier `könnte` / `testet` / `laut Mercedes` correct
- [ ] Mobile contrast, font size, line breaks, top/bottom/right safe areas
- [ ] No visual clutter, generic fake AI hardware, ugly artifacts or forced CTA
- [ ] Matches previous approved slide's series look
- [ ] Output file actually created and opened/verified
- [ ] No music or unwanted audio
- [ ] User approves before proceeding

## Integration with existing 12 numbered stages
- Stages 01–03: same research, fact-check and asset/rights verification, adapted from video to photos.
- Stage 04: write all slide headlines in German and storyboard 5–8 slides.
- Stage 05: N/A for Photo Mode — no VO needed.
- Stage 06: slide-by-slide photo storyboard and visual assignments, not source video timecodes.
- Stage 07: still-image composition/rendering **one by one** with user review.
- Stage 08: N/A video SFX/transitions — simple graphical annotation only, NO MUSIC.
- Stage 09: image/text/legal fact QA on final ordered slide files.
- Stage 10: export original-resolution PNG/JPG set and preview/contact sheet where useful.
- Stages 11–12: same publication package and real performance analysis, adapted to photos.
Only the production format differs; the accuracy, rights and honest QA rules do not.
