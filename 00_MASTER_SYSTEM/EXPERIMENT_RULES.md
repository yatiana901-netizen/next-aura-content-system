# Experiment Rules — Canonical

## Principle
Organic TikTok testing is a **quasi-experiment**, not a laboratory A/B test.

Topic, freshness, visual quality, brand recognition and distribution can all change performance.

## One-major-variable rule
When possible, keep most creative choices stable and change one major variable:
- duration
- CTA type
- hook family
- presenter usage
- caption style

Do not change several major variables at once and then claim one caused the result.

## Do not invent significance thresholds
Do NOT use arbitrary rules such as:
- "1,000 views is enough"
- "10 percentage points is noise"

unless our own historical account data supports those thresholds.

## Better comparison
Use repeated tests and compare:
- medians across several comparable videos
- same content pillar
- similar freshness
- similar visual quality
- same CTA when testing duration
- similar duration when testing CTA

Treat one-video differences as directional, not causal proof.

## Duration
Current buckets are experiments:
- 35–50s
- 50–60s
- 60s+

For Creator Rewards-targeted posts, use a safe buffer above the platform's one-minute requirement rather than designing exactly at the boundary.

## Metrics
Prioritize:
- average % watched
- completion
- shares / 1k
- saves / 1k
- follows / 1k
- profile visits / 1k

Average watch time is still useful, but compare carefully across different durations.

## Rule promotion
A creative hypothesis becomes a canonical rule only after repeated evidence.
