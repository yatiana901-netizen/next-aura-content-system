# Production Workflow — Canonical Gates

## 1. Topic Gate
Approved only if it passes:
- freshness
- niche fit
- hidden angle
- visual potential
- German audience relevance

## 2. Fact Lock
Before final scripting:
- verified facts
- source URLs
- publication date
- event date
- target market / region
- metric meanings
- prototype vs production
- peak vs sustained
- uncertainty noted

## 3. Rights Gate
Before relying on footage:
- source identified
- reuse status known
- watermark checked
- rights proof saved where necessary

## 4. Script Lock
One final German VO.
No filler.
Every sentence has a visual.

## 5. Asset Lock
Exact files and timestamps chosen.
Missing visuals trigger script rewrite, not fake evidence.

## 6. VO Lock
Final ElevenLabs take selected.
Only then build the final timeline.

## 7. Edit Lock
Check:
- first 3 sec
- first 8 sec
- pacing
- captions
- transitions
- SFX
- 9:16 framing
- no technical mismatch

## 8. Compliance Gate
Before publish:
- copyright / asset rights
- AI disclosure
- Creator Rewards duration/originality if relevant
- account status
- no unsupported claims

## 9. Publish Lock
Save:
- final caption
- hashtags
- cover text
- posting time
- final export filename

## 10. Postmortem
At 24h / 72h / 7d, record performance and lessons.
Promote only proven lessons into the canonical master system.
