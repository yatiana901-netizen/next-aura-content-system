# Hook Rules — Canonical

## Goal
The first 1–3 seconds should create a clear curiosity gap without sacrificing accuracy.

This is a **creative operating principle**, not a TikTok-issued timing law.

## Strong hook types
- **Visual mystery first**
- **Known headline, unknown detail**
- **Contradiction**
  - heavy yet fast
  - huge yet precise
  - simple-looking object hiding complex engineering
- **Strong number with immediate meaning**
- **Problem → unexpected technical solution**
- **Result first, explanation second**

## Internal hook competition
Before finalizing, compare multiple approaches internally:
- contradiction
- hidden detail
- visual mystery
- number
- engineering problem
- unexpected cause

Keep only the one with the strongest **curiosity-to-clarity ratio**.

## German style
- natural spoken German
- short sentences
- direct
- no literal translated-English clickbait
- no fake urgency
- no mixed-language sentence in final German copy

## Avoid
- “Du wirst nicht glauben…”
- “Das verändert alles”
- generic “Das ist verrückt” without proof
- long setup before the interesting part
- unsupported “kaum jemand spricht darüber”

## Visual rule
Whenever possible, the first visual should itself create the question.
Do not begin with the presenter if real footage can create a stronger visual hook.

## Guess → Reveal
Use only when the question has:
- a clearly defined comparison,
- a defensible answer,
- and no misleading ambiguity.

If the correct answer depends heavily on speed, operating state, setup or conditions, state the condition in the question or avoid the format.

## Testing rule
Timing ideas such as:
- micro-hook every 5–8 seconds,
- reveal at a fixed timestamp,
- fixed presenter timing,
are **testable hypotheses**, not canonical laws.
