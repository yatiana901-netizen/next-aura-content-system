# Hook Rules

## First 1–3 seconds
The viewer must immediately see or hear:
- a surprising result,
- a contradiction,
- a powerful number,
- a visual mystery,
- or a hidden detail behind a known headline.

## Preferred hook types
- Known headline, unknown detail
- Visual proof first
- Surprising number with immediate context
- Contradiction: heavy yet fast, huge yet precise, etc.
- Problem → unexpected engineering solution

## Avoid
- "Du wirst nicht glauben..."
- "Das verändert alles"
- generic hype
- claims that cannot be proven
- long setup before the point

## German
Natural spoken German. Short, direct sentences. No translated-English clickbait.

## Rule
Before fixing the final hook, compare multiple internal approaches and choose the one with the strongest curiosity-to-clarity ratio.
