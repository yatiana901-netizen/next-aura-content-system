# Hook Rules — Canonical

## Goal
The first 1–3 seconds must create a clear curiosity gap without sacrificing accuracy.

## Strong hook types
- **Visual mystery first**
- **Known headline, unknown detail**
- **Contradiction**
  - heavy yet fast
  - huge yet precise
  - simple-looking object hiding complex engineering
- **Strong number with immediate meaning**
- **Problem → unexpected technical solution**
- **Result first, explanation second**

## Internal hook competition
Before finalizing, compare multiple approaches internally:
- contradiction
- hidden detail
- visual mystery
- number
- engineering problem
- unexpected cause

Keep only the one with the strongest **curiosity-to-clarity ratio**.

## German style
- natural spoken German
- short sentences
- direct
- no literal translated-English clickbait
- no fake urgency

## Avoid
- “Du wirst nicht glauben…”
- “Das verändert alles”
- generic “Das ist verrückt” without proof
- long setup before the interesting part
- unsupported “kaum jemand spricht darüber”

## Visual rule
Whenever possible, the first visual should itself create the question.
Do not begin with the presenter if real footage can create a stronger visual hook.
