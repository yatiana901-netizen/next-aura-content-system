# Flow AI — Canonical Prompting Rules

## Presenter animation
Preserve exact identity:
- black technical hooded jacket
- black ribbed balaclava
- thin rectangular dark glasses
- black broadcast microphone
- graphite studio
- subtle blue rim lighting

## Performance
The presenter should look like a real social-media technology creator:
- direct eye contact
- natural blinking / breathing
- 1–2 purposeful gestures
- controlled posture
- realistic fingers
- one continuous take

## Avoid
- robotic gestures
- repeated gestures across videos
- exaggerated pointing
- sudden body motion
- body warping
- hand / finger deformation
- camera shake
- influencer overacting

## Shot design
Tailor every prompt to the exact line:
- correction / “no” → subtle head shake / open palm
- explaining scale → restrained hand spread
- linking concepts → one flowing multi-point gesture
- final precision → indicate one exact point, then subtle nod

## Technical visual animation
When animating engineering images:
- camera motion should do most of the work
- preserve geometry
- no random moving components
- no invented parts
- no neon sci-fi effects
- no fake electricity
- no morphing
- use realistic parallax, reflections, rack focus and lighting changes

## Start / end frames
If using start + end:
- same object identity
- same geometry
- same lighting logic
- same environment
- clear camera path between frames
